### 差し戻し 1 回: `index.html` の head が落ちていた

計画は「`index.html` は Vue scaffold 側へ置換」だったので Codex の判断は指示どおりだが、
**scaffold 版が旧の head を捨てていた** — `lang="ja"` / viewport の `maximum-scale=1.0,
user-scalable=no` / `color-scheme` / `theme-color` / `apple-mobile-web-app-*`。

**これらは React 固有ではなく UI 挙動そのもの**で、とくに `user-scalable=no` は
**タブレットでの 1 球入力中のピンチズームを抑える**。「全く同じものを作る」目標に照らして
黙って落とすべきではないと判断し、差し戻して復元した。

`manifest.webmanifest` と icon の link は**参照先の資産が未移植で 404 になる**ため見送り、
理由をファイル内にコメントで残した(後続ステップで資産ごと移植する)。

### ネットワーク例外

設計書 12.1 の例外として `PITCHLOG_ALLOW_NET=1` を使った(PO 了承)。
**ラッパーが `PITCHLOG_NET_REASON` を必須にしていて、理由なしでは起動を拒否した** — 機構が
例外運用の記録を強制している。

### 気づき

- **サンドボックスと npm/pnpm のキャッシュ** — 書き込み可能領域が worktree と `/tmp` に
  限られるため `~/.npm/_cacache` が `EROFS` で弾かれる。`COREPACK_HOME` を `/tmp` へ逃がして回避した
- **`ステップ進捗: 不明(無記法の実装コミット混在)`** — 確定ゲート中に `.claude/core-areas.json`
  (`.json`)を触った無記法コミットがあるため。6.1 が「`.claude` の設定ファイルは文書扱いしない」と
  定めているので**規約どおりの顕在化**だが、**文書ゲートの反映で `guard_paths` を触るのは正当な
  作業**なので、台帳の候補として起票する
