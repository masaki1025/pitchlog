### 4 周目 — 判定と即時 PO 裁定の起動(7.3-6)

**対象**: 反映差分と影響節(7.3-4)。**判定: `P0 0 / P1 2 / P2 0`**。**2 件とも起因**。

| # | 重大度 | 起因 | (A)/(B) | 要旨 |
| --- | --- | --- | --- | --- |
| 1 | **P1** | 起因 | (A) | **入口 0 本の PR で ④ を検査しても、結果を本ゲートのどの判定単位へ帰属させるか決まらない**。本表「適用単位」は**判定の対象を当該 PR が開く入口の集合に限る**と定めており、追加行が「適用単位を変えない」と宣言していることとも矛盾する |
| 2 | **P1** | 起因 | (A) | **「当該 PR が実スキーマへ加えた・変えた DB 側の経路について書く」では、本書だけを改訂する PR で記録対象が空になる**。本表は本書の改訂を再実行の契機としているのに、その PR が加えた DB 側の経路は 0 件である |

#### 原因 — 既存条文に先在する食い違いを、射程内では閉じられない

**本表は再実行の契機を 3 つ定める**(「本書の責務」行):
**① 実スキーマの適用 ② 本書の改訂 ③ 入口を開く PR**。
**一方「適用単位」行は③にしか判定単位を与えていない** — 「判定の対象は当該 PR が開く入口の集合に限る」。
**①②を契機とする再実行には、判定単位がそもそも無い。**

**これは本注記が持ち込んだ欠陥ではなく、approved 済みの v0.4 に先在する。**
本注記が①②に触れたことで表面化した。

**2〜4 周目の指摘は、すべてこの 1 点の別の言い方である。**

| 周 | 置いた場所 | 壊れた理由 |
| --- | --- | --- |
| 2 | 入口の有無 | 4 件は DB 層の要求なので入口で測ると取り逃がす |
| 3 | DB 側の経路 + 入口。範囲は「適用単位」へ委任 | 委任先が①②を覆っていない |
| 4 | 判定単位を DB 側の経路と明示 | 「適用単位を変えない」と両立しない |

**「適用単位」は ADR-004 の裁定 A の条文化であり、本改訂の「変更しない範囲」である。**

**推奨が誤っていた** — 争点は収束しつつある 1 点ではなく、**射程外に原因がある 1 点**だった。
