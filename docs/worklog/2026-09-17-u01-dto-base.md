## 決定

**`U-01` は「決める側」になる。** ページングの形・ID の表現・時刻の保持形式は**要件書にも正本にも決定が存在せず**、
決めると**下流 5 単位への事実上の先決**になる。**許した条文も禁じた条文も無い**ので、**本計画書の承認をもって線引きとした**。

| 決めたこと | 内容 |
| --- | --- |
| **ページング** | **形だけ。値は決めない**(PO 判断 2026-09-17)。`limit` 必須・既定値なし・下限 1 / **不透明な継続文字列**。`total` を持たない |
| **ID** | `EntityId` = `uuid.UUID`。**実装事実に合わせた判断であって正本の帰結ではない**。**認可判定に使わない** |
| **時刻** | `Timestamp` = aware。**精度・丸め・保持形式は決めない** |
| **基底** | `BaseSchema`(`extra="forbid"`)/ `ReadSchema`(`from_attributes`) |
| **写像** | `location` はドット連結。**現行実装の形を確定してテストで固定するだけで `errors.py` を触らない** |

**`ResponseValidationError` の 500 は別タスクへ送る**(塞ぐと射程が器へ戻る)。
**禁止語検査は二重に守る** — 上流 7 語 × 差分行(本計画書の式)/ 実装 5 語 × 全文(既存テスト)。

### 出続けた 2 テーマ(**どちらも私の書き方の癖**)

**1. 根拠の射程を強く書く。** 条文を読むと必ず「そこまでは言っていない」が出た。撤回した主なもの:

- **`NFR-014` を「ログに出さない」の根拠にした** — 実際は「**リポジトリに含めず環境変数で管理する**」であり**ログの規定ではない**
- **`NFR-005` を `total` を置かない根拠にした** — **`COUNT` は同条が禁じる「全件読み込み型」ではない**(むしろ是とする側)
- **`FR-041`/`FR-034` の「切り捨てず 400」を件数上限一般へ広げた** — **比較対象テナント集合の規則**
- **`set_config` を根拠に「DTO にテナント識別子を載せるのは正本と逆向き」とした** — **DB の RLS 文脈の規律**であり DTO の禁止ではない
- **DoD を「3 本の原典の具体化」と書いた** — **どの原典も DTO のテナント識別子を禁じていない**ので導出できない

**2. 同じ事実が複数ファイルにある。** 1 箇所直して別ファイルに古い記述を残す型が **3 周連続**。
**TSK-317 の 2〜3 周目とまったく同じ**で、そこで原因まで特定していたのに再発させた。
**手当ても 2 度中途半端にした**(2 周目に結論だけ外し、3 周目に詳細節を残した)。
**最終的に `research.md` の「未解決・申し送り」節を丸ごと落とし、「本書は判断を持たない」と宣言**して畳んだ。
