## 決定

**閉包の入口にゲートを 1 つ置き、置換が済んだ後は素通りさせる。**

```
① claims が 存在・配列・空でない・要素がオブジェクト(両側)
② 全行が receiving_task_id を持ち、非空文字列(両側)
     ①② が確かめられない → red
③ 基準版に対象行があるか
     ある → 4 段をそのまま
     無い → (a) 基準版の全行が最終文法に一致 かつ (b) HEAD にも 0 件
             どちらかが崩れていれば red
```

**固定 SHA は置かない**(基準の固定は `TSK-421` の射程)。**`contracts/` は 1 バイトも変えない。**
