### 機械検査の射程(**全廃はしない** — 6 周目 `P1-3`)

裁定台帳・seal は作らないが、**表構造の検査は機械化できるので残す**。
以下は**実測で動作を確認済み**のコマンドである(6 周目 `P0-4` で私の grep が
`\|` をリテラルと解釈して **false green(0 件)** になっていたため、すべて実測した):

```bash
R=docs/features/legacy-column-mapping/research.md
S='/^\| # \| 列名 \|/,/^\*\*JSON 列は固定長/'                    # 2 節センチネル表
LG='/^\| ID \| 対象 \| 分類 \| 原典照合の判定 \|/,/^$/'          # 1 節 判定表(ステップ 2 で見出しから「案」を外す)
LX='/^\| ID \| 論点 \| 衝突相手/,/^$/'                            # 3 節 判定表(同)
HIST='^## 履歴・非現行[(]参照しない[)]'                            # ステップ 3 で新設する固定見出し
#   ⚠️ `\(` は BRE(grep)ではグループ開始・ERE(awk)ではリテラルになり **grep=0 / awk=1** に割れる。
#      `[(]` `[)]` は両方でリテラルなので統一できる(9 周目 `P1-1` — `\|` と同型のミスを 2 度した)

# ① 88 列の一意網羅 — **uniq 前の行数も検査**(8 周目 P0-3: uniq 後だけでは重複行を通す)
awk "$S" "$R" | grep -cE '^\| [0-9]+ \|'                        # → 88
diff <(seq 0 87) <(awk "$S" "$R" | grep -oE '^\| [0-9]+ \|' | grep -oE '[0-9]+' | sort -n | uniq)   # → rc=0

# ② 【なし】行の件数
awk "$S" "$R" | grep -c '【なし】'                                # → 22
#   (**成果物レビュー 1 周目 `P1-3` で 21 → 22**: 列 85 `bottom_lrs` は `DL:229` が
#    「後攻の同上」とするだけで、参照先の列 81 自身が `DL:228` にセンチネル記述を持たない)

# ③ 判定 ID の exact-set — **判定表の先頭列のみ**を対象(8 周目 P0-3: 全文の一意集合では欠落・重複・誤割当を通す)
awk "$LG" "$R" | grep -oE '^\| `DM-LG-[0-9]+`' | grep -oE 'DM-LG-[0-9]+' | wc -l          # → 16(表の行数 = 割当数)
diff <(seq -f 'DM-LG-%02g' 1 16) <(awk "$LG" "$R" | grep -oE '^\| `DM-LG-[0-9]+`' | grep -oE 'DM-LG-[0-9]+' | sort)   # → rc=0
```
