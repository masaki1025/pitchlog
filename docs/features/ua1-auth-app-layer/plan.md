## 2. スコープ

### やること

1. **提示値の署名と検証**(HMAC-SHA256・**定数時間比較**)。**公開入口を 1 つ**にし、**全呼び出し元を試験で覆う**
2. **検証済みのテナント ID を返す公開入口** — 署名を照合した ID を `authn.verify_token()` へ渡し、
   **非 NULL の `tenant_id` が返ったときだけ**それを返す。**`TenantContext` は作らない**(裁定 b')
   **あわせてログアウトの保護された入口を持つ**(**裁定 ⑫**)— **署名を照合した ID だけを `authn.logout()` へ渡す**。
   **条文の正は `data-model.md:1687`(8-3 節 検証の手順 ②)の逐語「検証・延長・ログアウトのすべてに掛かる」**。
   **`authn.change_password()` は同条文の列挙に無い**ため、**本単位は入口を持たない**(δ が持つ)
3. **署名鍵の環境変数**(暗号論的乱数 256 ビット以上・**欠落や短い鍵では起動しない**)と設定サンプルの記述
4. **DB 接続がローカルか証明書検証付き TLS であることの検証**(`data-model.md:1543`)

   DB 接続の検証を `backend/src/pitchlog/db/engine.py` の `create_engine()` へ。
   **`authz/` 内の関数を単体で呼ぶだけでは合格としない**(計画レビュー 1 周目 `P1`)

7. **`docs/design/data-model.md` 12-8 節の残件 1 行の現行化**(裁定 b' の追随 — §3・§4-8)

### 4-2-0. β が提供する関数の契約(**2026-10-05 に当方が原典で確認**)

**典拠**: `feature/ua1-auth-db-layer`(PR #96・head `e10c0234`)の `contracts/authz/product/function-bodies/functions/` 配下。

| 関数 | 契約 |
| --- | --- |
| `authn.login(team_name text, password text) RETURNS uuid` | 成功 = 発行したトークン ID。**失敗はすべて NULL**(存在・状態・誤り方を区別しない) |
| **`authn.verify_token(p_token_id uuid) RETURNS uuid`** | **成功 = トークンの `tenant_id`**(`:55` `RETURN token_tenant_id`)。**失敗は全経路 NULL**(`:26` `:30` `:49`)。NULL になるのは **トークン不在 / 認証情報不在 / 主体とトークンのテナント不一致 / 世代不一致 / テナント無効 / 退役済み / 期限切れ / 有効期限の設定値の欠落**。**呼ぶたびに期限を延長する(副作用あり)** |
| **`authn.change_password(p_token_id uuid, p_current_password text, p_new_password text) RETURNS boolean`** | **トークン ID から主体を内部で解決し**(`:25`)、**その主体の認証情報だけ**を更新する(`:59-63` `WHERE auth_subject_id = initial_subject_id`)。**引数に主体もテナントも無いので、呼び出し元は別の主体を選べない**。更新の前に `verify_token` と同じ有効性条件を確かめ、満たさなければ何も更新せず `false`。**トークンの期限は延長しない**(ただし**認証情報は更新するので副作用はある** — ハッシュ・世代・変更日時。本体の `UPDATE` は `tenant_credentials` の 1 文だけ)。**新しいトークンを発行しない**(`data-model.md:1694` と整合) |

**本単位の設計はこの契約から導かれる**:

1. **署名の照合は β に無い**(本単位の役割)。**署名照合を通った ID を `verify_token` へ渡し、
   非 NULL の `tenant_id` が返ったときだけそれを返す。** これで 8-3 節 `:1686-1690` のうち ①〜④ を満たす。
   **⑤(文脈の生成)は U-M1 が持つ**(裁定 b')
2. **`verify_token` は呼ぶたびに期限を延長する**(副作用あり)。**「検証だけ」の経路は存在しない。**
   **本単位は検証と延長を分けられない**
3. **`data-model.md:1538` の「パスワード変更の対象は検証済みトークンの認証主体に限る」は β 側で閉じている** —
   `change_password` が**トークン ID 起点**で主体を解決するため。**本単位は認証主体の ID を一切扱わない**
   (**2026-10-05 に u1 タブへ照会し、当方が原典で確認**)
