### 検査の射程

`tests/test_gap_register.py` のレポート検査は、区分1のID・状態を実資産と exact-set で照合し、各行の送り先を必須とする。区分2・3はID重複、送り先空欄、設計書の原文断片への解決を検査する。区分3のID集合を固定し、脱落も検出する。区分3の実測値39件は既存の `test_step102_both_required_set_differences_are_empty`、2817件と12件は既存の被覆検査が検証する。

機械は、引用先の文が当該課題を意味的に支持するか、33行で設計書の全ての未解消事項を尽くしたか、独立確認や人間署名が真実かを判定しない。これらは本書と設計書の全文を照合する PR の人間レビューに残る。`resolved` の5件に残る穴、39件・2817件の除外を「解消済み」と扱わない。
