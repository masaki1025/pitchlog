**① 根拠にしている「番人」が、主張どおりには働かない(実測で反証)。**

将来関数が足されたら必ず試験を書かされる」という前提に乗る。**通り抜けが 2 つある。**

| | 通り抜け | 典拠 |
| --- | --- | --- |
| A | **`SECURITY DEFINER` のトリガ関数は EXECUTE 無しで発火する** | `backend/tests/db/test_product_authz_cross_cutting.py:278-332` が **37 件すべて `has_function_privilege` false** のまま発火することを実証 |
| B | **RLS ポリシー式から呼ぶ形も EXECUTE 不要** | **現行の唯一の `SECURITY DEFINER` 関数がこの形** — `tenant_has_effective_membership` は `REVOKE ALL … FROM PUBLIC, pitchlog_app`(`backend/src/pitchlog/authz/product_control_access.py:168-170`)されているのにポリシー経由で効く |
