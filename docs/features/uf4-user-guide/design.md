## 抽出の範囲と方法

**抽出元**: `dd03160:frontend/src/screens/HelpScreen.tsx`(124 行)。`dd03160` = `dd03160044aa5932d3b5a025870c9a5a56d979ef`(旧リポジトリの固定コミット)。

**抽出対象は「JSX のテキストノードと `STEPS` の表示フィールド(title・body)」に限る。** 次は対象外とする(計画書 4 節ステップ 1 の合格条件):

| --- | --- |
| Tailwind の class 文字列 | 表示本文ではない。移植規則の別軸(class 文字列の比較)で扱う |

**漏れが無いことの示し方**: 下表の各行に `dd03160:…:<行>` の出典を付し、抽出結果と表 A の行を**一対一**で対応させる。**文字列リテラルの総数とは突合しない**(表示本文でないリテラルを多数含むため — 計画レビュー 2 回目 P0)。
