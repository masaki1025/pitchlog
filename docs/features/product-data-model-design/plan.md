## 4. 実装方針

### 重さ分類の根拠 = **コア領域**(`gpt-5.6-sol` / xhigh)

### 論点の (A)/(B) 分類(H-68 対策 — 台帳 `:835-844` の対応案 (c))

**(A) = この起草で決めないと後の作業が手戻りする / (B) = 実装時・実測後に決めれば足りる**。

**件数の内訳**: [research.md](research.md) の 16 件を起点に、レビュー 1 周目の指摘で **#1 の再枠付け・#9 の分割・#12 の新設・#10 の無条件化・#8 と #11 と #16 の (B) への移動**を反映した結果、**(A) 12 件 / (B) 10 件 = 22 件**。
