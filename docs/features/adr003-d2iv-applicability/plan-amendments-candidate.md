## 11/12の段階提供と従来MVPの差分

先行の受入条件は、U-F8から1球を送信し、506の実HTTP入口、U-S1単一適用核、U-R1記録権Port、U-X1 T1/T2の本物の計算・投影を**同一transaction**で確定し、隔離DBの原本から再読込できること。再送・閉鎖・失効・全取消・越境も実経路で検証する。これをAPIだけの成功、仮Port、手書き計算で代用しない。
