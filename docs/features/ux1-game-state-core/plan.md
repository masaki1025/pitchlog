### 判定の 4 値と合格証拠(**2 周目 `P1-4` / 3 周目 `P1-1`・`P1-2` の是正**)

**要件が求めていない計算は反例にならない。**

| 判定 | 必要な証拠 |
| --- | --- |
| **要件に不要**(**3 周目 `P1-1` で新設**) | **どの FR も当該の計算を要求していない**ことを要件の逐語で示す。**候補から外し、外した理由を残す** |
| **表現不能** | 当該 FR の**必要な入出力**を示し、**既存 8 種の `Expression`・`guardRefs`・`ReducerRule` の組で満たせないこと**を schema の構造から示す。**「読むコードが無い」だけを根拠にしない** |

## 6. テスト計画
