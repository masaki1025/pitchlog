### 5. §9 に無い新しい計算の形(候補基準一覧への追加が要るかの判断材料)

宣言モデルで書けるかどうかは判定していません。v2.10 で条文に現れた形だけを挙げます。

- **(a) 走者ごとに最初の一致を評価し、件数を数える**: 得点数は「`OUT3-04`となった走者数」(N:1161)、打点数は「算入となった走者数」(N:1163・1212)。走者ごとの観測入力(写像)を使います。走者は最大 3 人と打者で上限がありますが、§9 のどの候補もこの形を挙げていません。
- **(b) 1 遷移の中での段階の逐次適用**: 段階の順序が条文で定まりました。
  - 行の効果 → 攻守交代の共通後処理(カウントを 0 に戻す)。「その行のアウト効果を適用した後に実行する」(N:246・1437)
  - OUT3 → サヨナラの計上 → COLD 判定(N:1165)
  - 攻守交代の後の状態で再び終了判定(N:1640・1660)

  C21(走者の順序)とは別物です。
- **(c) 別の行への委譲**: INT-01・INT-03 は「採用された`resultId`の通常行が定める…全効果」を適用します(N:1464・1468・1470)。`secondary-result` で `score` になるときは、参照先の `batting-result` 行から適用します(N:1412)。どの行を使うかは入力で決まります。
