# 調査メモ: 同期プロトコル — ACK の応答契約と再送・undo の同期上の表現(後続 β)

## 問い

**後続 β の射程(7-1 / 7-3 / 7-6 / `C1`)は成立するか。** 成立しないなら、どこで切るか。
あわせて、**後続 α から持ち越した未決 3 件**が本タスクの射程に入るかを判定する。

調査サブエージェント **3 本**(spec-checker / legacy-analyst / decision-tracer)+ 原典の直接確認。

## 結論(要約)

1. **「7-1 / 7-3 / 7-6 を実装する」という射程は成立しない。** これらの節の**中核はサーバーの振る舞い**であり、
   backend は現状 `GET /health` だけ。7-3 の手順 2・3、7-6 の `U2`・`U2-a`〜`U2-c`、`DI1`〜`DI5` はいずれも
   サーバー側で、**`DI1`・`DI5`・`I1`・`B3a` は既に後続 γ へ送付済み**。
2. **成立する切り方は「ACK 応答の消費側 + 契約の型・オラクル固定」**(案 A)。
   これにより **後続 α の注入境界 7 点が実際に埋まり、α のコードが初めて動く**。
3. **`NFR-019(d)` の 6 項目のうち、β の射程で完結して書けるものは 0 件。** TSK-280 と同じ構図。
   **(a) 一致性は undo の一部だけ該当**し、**(c) E2E はサーバーが要るため書けない**。
4. **区分ラベルの誤りを発見** — 要件書の `NFR-019` は **(a) 一致性 / (b) 越境 / (c) E2E / (d) 故障系**で、
   **「(a) 単体」という区分は存在しない**。**後続 α の計画書とマージ済み PR 本文が誤っている**。
5. **α から持ち越した未決 3 件はいずれも過去に裁定された記録が無い。**
   とくに **`NFR-020` の 6 前提不成立時の挙動は、11-4 の未解決表にも項目が無く受け取り先すら設定されていない**。

| **(a) 一致性** | **undo の一部だけ** | `NFR-019(a)` の比較面が「**遷移後の履歴文脈(取消可能な操作のスタック全体)**」「**操作結果の区分(適用された / 取り消す対象が無い)**」を要求(要件書 `:920`)。**`U4` はここに載る**。ACK・再送・写像は NFR-018 の (α) 列挙に無く対象外 |
