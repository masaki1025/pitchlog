現時点の対象別経過措置はT1/T2だけで、T5/T6の製品型・提供SHA・接続は未提供。したがって、T1/T2が完成しても「断中の当日成績・球種分布追従」と「シーズン値/プリフェッチ」を満たしたことにはならない。U-F8の表示実装は進められるが、これらを含む1試合検証の合格はまだ出せない。
