# TSK-550 接続設計の未確定点

本書は実装前の判断表であり、関数名・型・値・DDL を製品契約として確定しない。

| 論点 | 既存契約 | 未確定の判断・受理先 |
| --- | --- | --- |
| 解決順 | FR-014: 試合上書き ＞ 大会規則 ＞ 区分既定 | 上書きの入力表現と、越境を検査する ID の帰属証明。U-X1 受理担当 |
| 戻り値 | 付録 F の検証済み規則 snapshot、保存済み値は非遡及 | 公開不変型と候補なし/越境/無効/読取失敗の具体型。U-X1 受理担当・TSK-395 呼出側 |

| 関数と ACL | アプリロールは両表を直接読めない | 制限関数の実行ロール、search_path、越境情報非漏洩、読み/設定の分離。認可面所有者・凍結基準受理 |
