# TSK-547 試合開始時の初期記録権に関する限定正本改訂

## 根拠と射程

U-S1 の承認済み R-17 は、初期記録権を `preparing` 作成ではなく**試合開始**時に付与し、sync-protocol 9-5 の試合作成行を分割する単独の小 PR を U-G1 統合前に確定すると定める。2026-10-18 の依頼者指示で U-R1 担当がこの限定起案と正式 7.3 審査を進める。これは R-17 の意味・U-G1/U-S1 の製品実装所有を変えない。

**対象**: `docs/design/sync-protocol.md` 9-5 の RG1 全経路表に `preparing` 作成と試合開始を分ける行、復元された`preparing`の初期付与時点、同節の列挙、11-4 の対応する検査行・RG1競合行、7.3 の履歴・索引追随。**対象外**: D4/V12/端末/復旧世代の物理方式、製品コード、運用 open/復元開始の実装、他の同期規則、正式認可/凍結資産と 7.7。

この文書作業は U-R1 新5の製品実装ステップから独立した正本ゲートとする。TSK-547 の限定計画と正本 v0.9 は、正式7.3敵対レビュー2回・反映2周の最終候補`f3351f2b`を対象に、2026-10-18にPOが承認した。最終反映差分は独立再レビュー未実施であることも承認記録に残す。この承認を U-R1 新5の製品実装、認可/凍結資産や7.7の許可へ流用しない。

**DoD**: 作成時と復元調整解除時に`preparing`試合へD4/V12を発行しないこと、開始時には同一transactionで初期付与すること、RG1中は両経路をB7で拒否し各経路の全変更（当該transaction内のスタメン記憶を含む）を取り消すこと、11-4の検査母集合とRG1移行競合に両経路を含むこと。既存D4対象が0件でも全域RG1を解除でき、解除後の`preparing`開始で過去D4を再利用しないこと。2026-10-18のPO承認で正本を `approved` に確定する。

最終HEAD `d643da6e` のharnessで、正本変更履歴の除去対象語との偶発的衝突1件と、確定済みの「既存D4対象だけ新D4、対象0件なら発行0件」を旧文言で照合する検査2件が失敗した。承認済みの意味を変えず、変更履歴の当該表現を訂正し、`tests/test_check_design_propagation.py` の3検査を実際の確定条件へ追随させる。旧条件の欠落と対象外へのD4発行を引き続き拒否し、同じ検査の全経路表に承認済みの試合開始行を含める。影響試験・文書検査後に通常コミット、push、CI再実行、PR本文更新を行う。これはステップ1のCI是正であり、新ステップや製品実装を追加しない。従前の7.3レビュー2回と独立再レビュー未実施の記録を維持し、本追随差分も独立再レビュー済みとは記録しない。本人逐行確認とマージは別ゲートのままとする。
