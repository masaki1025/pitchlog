- 前タスク: **TSK-280**(イベント契約の骨格・PR #43 マージ済み `76f0652`)

**TSK-280 はイベント契約の型と値の不変条件までを実装し、キュー・ロック・サーバー適用を前提とするものを
すべて後続へ送った。** 本タスクはそのうち**クライアント側**を引き取る。

**旧システムに移植元が無い。** TSK-226 の判定で **FR-012・FR-013 はいずれも ×**。
旧 outbox は「**送信失敗のリトライ器**」であって「オフライン記録の器」ではなく(オフラインで保持できるのは
「送信に失敗した最後の 1 球」だけ)、**状態機械そのものに移植元が存在しない**。
**移植すると要件違反になる逆実装のうち 2 件は `I-8` の改訂(2026-09-02・TSK-308 裁定 B-5/B-6・山田正輝)で「移植しない」と確定済み。**

### (B) 論点の実装判断(**正本が本書へ委譲した — ここで確定する**)

#### 論点 19-a: 端末内キューの永続化技術 → **IndexedDB**

| 判断 | 根拠 |
| --- | --- |
| **IndexedDB を採用する** | **`Q1` が「追記と D1 の採番を不可分に永続化する」ことを要求する**。ブラウザ内蔵ストレージでトランザクションを持つのは IndexedDB だけで、**localStorage には不可分性が無い** |
| **キューと `(試合, D4)` ごとの D1 カウンタを 1 つの `readwrite` トランザクションで読み書きする** | 失敗時に**行も D1 も消費しない**(`Q1`「片方だけが残る状態を作らない」) |
| **値は structured clone のまま保存する。JSON 文字列化しない** | TSK-280 のスロット型は **`unknown`**。JSON 化は **(B) 論点 17/18/26 の物理型を先取りする**(`undefined` が消え、Date が文字列になる) |
| **`navigator.storage.persist()` の結果を保持し、拒否を `Q6` の通知契約へ渡す** | `Q6`「永続ストレージの要求が拒否されたら、キューが消され得る旨を警告する」 |
| **D6・D7 は既存スロットを同じ D1 で不可分に置換し、採番しない** | `Q1` 後段・7-2 の「要操作 → 未送信」 |
| **IndexedDB が利用不能なら fail-closed(記録を開始しない)** | NFR-020「サイトストレージが利用可能」は単一書き手選出の 6 前提の 1 つ。**撤回済み案(警告して記録継続)を実装しない** |

**NFR-001 との関係**: 11-1 は「クリティカルパスに乗るのは**キューへの追記 + D1 の採番**の**端末内永続ストレージへ 1 回(不可分)**だけ」と構造化(`:1704`)し、
「不可分な 1 回」は**論理的な永続化処理の回数**であって物理 I/O 1 回ではない(`:1712`)。**1 トランザクションであることを spy で固定する**。

#### 論点 19-b: ローカル書き出しのファイル形式 → **JSON テキスト + 注入 codec**

| 判断 | 根拠 |
| --- | --- |
| **ファイルは `{ schemaVersion, exportedAt, events[] }` の JSON テキスト**。**イベントの原形(D1・D4・D5 を含む)をそのまま並べ、採番し直さない** | `X1` |
| **値の符号化は注入された codec が行う。既定 codec は「JSON 往復で同値にならない値」を fail-closed で拒否して顕在化する**(黙って変換しない) | **物理型を先取りしない**((B) 論点 17/18/26)。**壊すより顕在化する**。TSK-250 が列型を決めたら codec を差し替える |
| **往復同値性を機械検査する** — 書き出し → 取り込みでイベントが構造等価であること | `X1`「原形を保つ」 |
| **取り込み時に重複判定を作らない**。**原形のまま通常キューへ取り込み、同一 D5 の始末はサーバーの冪等処理へ委ねる**(同内容 = 保存済み結果の再掲 / **異内容 = `B3b`** / 判定不能 = 拒否) | `X2`「取り込み専用の重複判定を作らない」(**2026-09-05 の実装敵対レビュー P0-4 で是正 — 当初は「D5 の同一性だけで併合する」と読んでいたが、それ自体が禁じられている取り込み専用判定であり、同 D5・異内容の `B3b` を握り潰す**。再承認待ち) |

**既定 codec が拒否する値がある場合は、書き出しを失敗として顕在化し、部分ファイルを残さない。** これを申し送りに記録する。
