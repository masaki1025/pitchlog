# PO 判断シート: 旧 frontend 充足度調査から出た判断事項

**行数 = 24**(式: [research.md](research.md) §5 の 15 件 + §4-1 の 7 件 + 2〔WHIP・FIP / 旧 SPA 参照資料の置き場〕。内訳: 群 A = 11 / 群 B = 9 / 群 C = 4)。
