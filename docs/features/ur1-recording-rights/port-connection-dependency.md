**原子性と後続試験**: U-G1 は試合開始・スタメン・U-M2記憶・初期付与を同一 scope で全確定/全取消にする。U-S1 の同期核は③-aを認可後かつD5前、⑧を同じ scope の書込後・commit直前に置く。試合行→記録権世代行→RG1行の取得順を保つ。RG1閉鎖は D1付き経路 B7、P3 B10。実入口でのD5未消費、commit直前閉鎖の原本・台帳・投影全取消と越境は U-R1 新8・TSK-506 ステップ5の必須結合試験に残す。候補の単体/隔離試験だけで完了扱いしない。

**順序判断**: 全 Port は新5の現世代/V12/復旧世代判定と後続の引き継ぎ・復元契約に依存する。新8を新5より先へ移しても、TSK-506が要求する登録済み実 Port にはならない。現時点で待ちを短縮するための計画順序変更は提案しない。担当回答で独立した安全な先行単位が具体化した場合に限り、影響するステップとレビュー/7.7境界の最小追補を提示する。
