## 射程宣言(設計書 7.3-7)

### 本 ADR で確定する範囲

1. **`data-model.md` 12-4 節のマージゲートの適用単位を「当該 PR が開く経路」とした決定の
   経緯・理由・却下した案**(裁定 A)
2. **同ゲートの測定経路の充足条件を「HTTP 経路を開く PR は同一 PR にその経路の直叩きテストを
   含む」とした決定の経緯・理由・却下した案**(裁定 B)
3. **要件書 `NFR-019(b)` へ発効条項を置いた理由**(`NFR-018` との非対称の解消)

**本 ADR は規範を持たない。** 規範の所在は次のとおりで、本 ADR は**過去形 + 条項参照**で
決定を記録する。

| 規範 | 所在 |
| --- | --- |
| ゲートの適用単位・測定経路の充足条件 | **`docs/design/data-model.md` 12-4 節** |
| 越境テストの発効 | **要件書 `NFR-019(b)`** |

**検証**: 本 ADR の本文から**条項参照を外すと規範として読めなくなる**こと。
読めてしまうなら規範を持っている。
