### data-layer.md が記録している「移行の罠」（要点）
- **列名と中身の乖離**: 「タイムの種類」＝**エラー選手（守備番号1-9）**／「打席Id」＝**フリーコメント**（列名は歴史的遺物）
- **センチネル値の同居**: `0`(int)・`"0"`(str)・`""`・NULL が意味的に混在。旧UIは `"0"`/`0` を未入力の印として多用し、集計側は `x<=0`・`球速>0` で除外していた
- **プレースホルダの初期値**: 「後攻チーム」列の初期値が文字列 `"先攻チーム"`（逆）等
- **位置依存の復元**: `SELECT *` の列順に依存した読み出し（列名ベースで移行すべき理由）
